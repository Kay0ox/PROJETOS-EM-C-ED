# Estruturas de Dados: Lista 2 (Linguagem C)

Resolução da Lista 2 da disciplina de **Estruturas de Dados** (Ciência da Computação, UNIPÊ). Os exercícios cobrem algoritmos de ordenação, alocação dinâmica, structs, ponteiros e tipos abstratos de dados (TAD). O enunciado está em `LISTA1 - N2.pdf`.

## Questões

| Arquivo                | Tema                                                                 |
|------------------------|----------------------------------------------------------------------|
| `ED-lista2-questao01.c`| Ordenação com Selection Sort                                         |
| `ED-lista2-questao02.c`| Cadastro, exibição e exclusão de empregados com alocação dinâmica    |
| `ED-lista2-questao03.c`| Cadastro de aeroportos com vetor de ponteiros para struct            |
| `ED-lista2-questao04.c`| Conjectura de Goldbach para os pares entre 700 e 1100                |
| `ED-lista2-questao05.c`| Conjectura de Goldbach de 4 até um N informado                       |
| `ED-lista2-questao06.c`| Raiz quadrada pelo método de Newton-Raphson                          |
| `ED-lista2-questao07.c`| Ordenação com Quicksort recursivo                                    |
| `ED-lista2-questao08.c`| TAD de números complexos                                             |
| `ED-lista2-questao09.c`| Bubble Sort com contagem de comparações e trocas                     |

## Como compilar e rodar

Com o GCC instalado:

```bash
gcc ED-lista2-questao07.c -o questao07 -lm
./questao07
```

Troque o nome do arquivo para rodar as outras questões.
